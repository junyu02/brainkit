# AGENTS.md — 二脑（Second Brain）代理须知

你正站在一个人类与 AI 共享的长期记忆库里。这里的每个 Markdown 文件都是记忆，结构即语义。**先读完本文件再动任何东西。**

## 这是什么

- 本 vault 是唯一长期记忆真源（single source of truth）。语义索引（MemPalace）、热索引（MEMORY.md）都只是它的可重建投影。
- 分区语义：01-项目（项目专属记忆）/ 02-知识（参考知识）/ 03-经验（跨项目经验教训）/ 04-对话（会话记录）/ 05-persona（用户画像）/ 07-随笔 / 08-观察（自动采集的过程观察，未经确认，勿当事实引用）/ 09-周报（每周工作回顾）/ 06-归档 / 99-inbox（路由待定暂存）/ 00-系统（脚本、台账、状态——系统自身，不是记忆）。
- 08-观察 与其他分区的信任级别不同：观察是"过程自动记"，事实层是"经审核确认"。引用观察层内容时须注明其未经确认。

## 硬规则（违反即破坏系统完整性）

1. **写入唯一入口**：任何记忆的新建/修改必须通过 `00-系统/scripts/cli/brain-write.mjs` 管道（传你的 `--source` 身份）。它负责路由校验、查重、索引更新、台账记录。**禁止直接创建或编辑记忆 Markdown 文件**——绕过管道的写入没有查重、不进索引、无审计，等于污染。
2. **禁止删除**：不要 rm 任何记忆文件。过期/错误的记忆通过管道修订或交人类裁决。
3. **只读随便**：读取、grep、统计任何文件都欢迎——这个库就是为被读而存在的。
4. **00-系统 下的脚本与状态文件**不是记忆，修改它们属于系统工程，需要人类批准的变更流程。
5. **敏感内容**：凭证、密码、密钥类内容不得写入本库任何位置。

## 常用入口

- 写记忆：`node 00-系统/scripts/cli/brain-write.mjs --type <experience|project|reference|user-profile|weekly> --source <你的身份> --title ... --description ... --provenance ...`（正文走 stdin 或 --body）
- 看系统状态：`状态总览.md`（生成的仪表盘，勿手改）
- 协议细节：`VAULT-MEMORY-PROTOCOL.md`；结构规范：`00-系统/VAULT-STRUCTURE.md`
- 语义检索：MemPalace CLI/MCP（只读；观察层默认不应参与常规检索）
- 安装器的逻辑与原理：`docs/INSTALLER.md`——**动 `install.mjs` 之前必读**。注意仓库里有两个 `recover`：`publish.mjs --recover` 会动手修，`install.mjs recover` 只诊断不修复。

## 给未来移植者

本文件是 vault 自描述的一部分：任何 agent 无论宿主，站进这个目录读到这里，就应当知道如何安全地与这个记忆库共存。规则冲突时，以宿主的控制面裁决为准，本文件为兜底。
